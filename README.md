# Academic-Formula

手机竖屏学术表达训练，React + Vite。

## 两种训练模式

- 句型专项：选择句型，自动安排未用该句型完成的考点，确认完成后自动进入下一考点。
- 考点专项：选择作曲家或作品，依次安排尚未完成的句型，确认完成后自动进入下一句型。
- 每项训练均为知识定位 → 句型填充 → 独立生成，用户确认完成，无 AI 评分。

两种模式共用浏览器本地存储中的 `af-training-records-v1`。一条记录保存考点、句型 ID、模式、知识答案、拼句、独立论述及完成时间。句型档案、考点地图和学习档案均从这些记录计算；刷新可恢复未完成训练。记录仅在同一浏览器内共享，不跨设备同步。

旧版聚合计数保留原存储键，不转换成具体完成记录，避免把无法确认的句型与考点组合标为完成。

## 开发与验证

- `npm run dev`：开发预览。
- `npm run build`：类型检查并生成生产构建。
- `npm test`：使用 Node 22.6+ 验证双向进度、排程及槽位填充。
